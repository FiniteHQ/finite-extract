# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public issue.**

Instead, please use [GitHub's private vulnerability reporting](https://github.com/FiniteHQ/finite-extract/security/advisories/new) to submit your report. This ensures the issue can be addressed before public disclosure.

You should expect an initial response within 72 hours. We will work with you to understand the issue and coordinate a fix and disclosure timeline.

## Supported Versions

Only the latest release on the `main` branch is supported with security updates.
